## Standing content rules

Binding on everything produced for this project.

1. **Original work only.** No characters, missions, UI, logos, assets, code,
   dialogue or artwork from any existing game or studio. "Open-world crime game"
   is a genre, not a template to copy.
2. **No real organisations.** Both factions are invented. No real gang, real
   Kingston group, or real criminal organisation anywhere.
3. **No real businesses.** Every shop, mall, garage and pub is fictional.
4. **No real estates.** The game's estate is fictional and in a fictional
   location. Real, occupied, identifiable estates are never depicted as gang
   territory — real people live there.
5. **No mapping-provider content.** Geography was researched, then rebuilt as an
   original stylised world. No tiles, imagery, labels, styling or data.
6. **No real people.**
7. **Original music only**, or written game-scoped licences.
8. **Portray Greenside with dignity.** Residents are people, not scenery.
